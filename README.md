# 🛡️ 坦克大战 · Tank Battle

一个纯 HTML / CSS / JavaScript 编写的经典坦克大战（Battle City 风格）网页游戏，单文件、零依赖，打开即玩。

## 在线试玩 / 运行方式

- **直接运行**：双击 `index.html`，用任意现代浏览器打开即可。
- **本地服务器**（可选）：
  ```bash
  # 在仓库根目录执行
  python -m http.server 8000
  # 然后浏览器访问 http://localhost:8000
  ```

## 玩法

保卫屏幕底部的基地（🛡️ 旗帜），消灭所有敌方坦克。基地被摧毁或生命耗尽则游戏结束。

### 操作

| 按键 | 功能 |
| ---- | ---- |
| `W` `A` `S` `D` / 方向键 | 移动坦克 |
| `空格` / `J` | 射击 |
| `P` / `Esc` | 暂停 / 继续 |

### 元素

- 🧱 **砖墙**：可被子弹摧毁
- ⚙️ **钢墙**：普通子弹无法摧毁（满级后可以）
- 🌊 **水域**：坦克无法通行，子弹可以飞过
- 🌿 **草丛**：隐藏坦克，提供隐蔽
- 🛡️ **基地**：被摧毁即游戏失败

### 道具（击毁敌人随机掉落）

| 道具 | 效果 |
| ---- | ---- |
| ★ 星星 | 升级火力：更快射速 / 更快子弹 / 穿透 / 摧毁钢墙 |
| 🛡 护盾 | 短暂无敌 |
| ♥ 生命 | 额外生命 |
| 💥 炸弹 | 消灭场上所有敌人 |
| ⏱ 冰冻 | 敌人短暂定身 |

### 敌方类型

- 🔴 普通坦克（100 分）
- 🟠 快速坦克（200 分）
- 🔴 重型坦克（300 分，3 点生命）

随着关卡提升，敌人会更多、更快、更耐打。

## 技术说明

- 原生 HTML5 `<canvas>` 渲染，`requestAnimationFrame` 游戏循环
- 纯 JavaScript，无任何外部依赖或框架
- 单文件结构，方便部署到 GitHub Pages 等任意静态托管
